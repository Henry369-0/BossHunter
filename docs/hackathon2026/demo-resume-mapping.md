# 保存分支的岗位简历示例

此页面保留 powerycy 原始 hackathon judge demo 的虚构候选人、公司与岗位资料。Henry369-0 的 fork 改进让岗位页在窄屏下正常收缩，并让已确认岗位分别预览对应内容；不代表真实用户经历或真实 AI 生成结果。

工程岗位前置“多步骤 AI 工作流产品”，产品经理岗位前置“求职流程自动化工具”。摘要与关键词对应岗位，但两项项目的原有四条事实句保持不变。负责人岗位缺少示例团队管理资料，会提示“示例资料不足”，不生成管理履历。多选可逐项切换预览；无选择无法继续，也不会回退到默认工程师简历。

示例预览不调用 AI API、不生成 PDF 文件、不发送消息、不访问招聘账号。工程师和产品经理的文件名仅为演示名称。原项目贡献来源与新 fork 改动分别保留。

验证角色映射：在 `src/bosshunter/web/frontend` 运行 `npm test`。使用仓库已有 TypeScript 依赖和 Node 自带测试框架，没有新增依赖。`npm run build` 同时检查 TypeScript 和生成前端；Pages 的 `VITE_DEMO_ONLY=1` 构建仍使用原隔离路由。

人工验收：在 320px、390px、桌面宽度分别跑工程师单选、产品经理单选、多个岗位切换、清空选择与负责人资料不足，检查项目顺序、求职意向、原四条事实句、虚构资料标签和页面没有横向溢出。
