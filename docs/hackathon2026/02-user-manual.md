# BossHunter 公开使用手册

## 最快体验：评委演示模式

打开：<https://powerycy.github.io/BossHunter/>

无需注册、登录、部署、API Key 或真实简历。建议预留 3 分钟。

### 第一步：看 AI 怎么筛

1. 点击“开始 3 分钟演示”。
2. 页面会展示 6 条模拟岗位中的 4 条候选项，并按深度评分排序。
3. 点击任意岗位卡片，查看 JD 摘要、预筛分、深度评分、评分理由、风险和招呼语。
4. 展开“查看 2 个被过滤岗位与具体原因”，确认系统不是只会给高分。

### 第二步：由人决定

1. 默认勾选两个高匹配岗位，也可以取消或改选。
2. 点击“人工确认并继续”。
3. 查看漏斗：演示只把选中岗位标记为人工确认，“真实发送”保持为 0。

### 第三步：处理跟进

1. 点击“模拟收到 HR 消息”。
2. 查看对应岗位的虚构简历示例：工程岗位前置 Python 工作流项目，产品经理岗位前置求职流程产品设计项目。
3. 多选岗位时可逐项切换预览。负责人岗位缺少示例管理资料，会提示资料不足，不生成管理履历。
4. 检查“没有新增事实”和“不自动发送”两个边界；这只是示例资料的重排，不调用 AI API，也不生成 PDF 文件。
5. 点击页头“重新演示”可随时重置。

## 演示数据说明

- 林小满、所有公司和所有岗位均为虚构。
- 评分和文案是固定演示结果，用于让每位评委获得同样的可复现体验。
- 演示页面不连接招聘平台，不调用 AI API，不上传或保存用户信息。
- 本 fork 保存分支的角色映射、原始资料来源与验证说明见 [岗位简历示例](demo-resume-mapping.md)。

## 真实本地版本

真实版本适合愿意自己管理招聘平台账号和 AI 服务的个人求职者。

### 环境

- Python 3.10+
- Node.js 22+
- 最新稳定版 Google Chrome
- 用户自己的 Anthropic 或 OpenAI 兼容 AI 服务

### 安装

```bash
git clone https://github.com/powerycy/BossHunter.git
cd BossHunter
pip install -e .
bosshunter web
```

浏览器打开 `http://127.0.0.1:8686`，上传自己的 Markdown 或 Word 简历，设置岗位与 AI 服务。API Key 只应在本地面板输入，不要粘贴到聊天、Issue 或提交文件。

### 使用前检查

1. 在 Chrome 开启远程调试。
2. 在同一个 Chrome 窗口自行登录招聘平台。
3. 执行 `bosshunter connect` 检查浏览器连接。
4. 执行 `bosshunter ai-status` 检查 AI 服务。
5. 确认简历是真实个人简历，不是示例模板。

### 启动与停止

```bash
bosshunter run
```

系统会运行采集、评分和人工确认。只有确认的岗位才进入后续沟通准备。Web 工作台可请求停止；命令行可按 `Ctrl+C`。

### 安全建议

- 只在个人求职期间短期、低频使用。
- 保持发送时间窗、每日上限与随机间隔。
- 发送前逐项检查岗位和招呼语。
- 不要用它绕过平台限制或进行批量骚扰。
- 第三方平台规则可能变化，使用者需要自行核对并承担账号风险。

更完整的本地配置和命令说明见仓库 [README](https://github.com/powerycy/BossHunter#readme)。
